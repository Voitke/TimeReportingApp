# TimeReportingApp

A protfolio full-stack web application showcasing my skills.

**Backend (Java 25 + Spring 7 + Spring Boot 4):**
- RESTful API design with Spring MVC
- Pagination and filtering support
- Safe, transcational database access with Spring Data JPA (Hibernate) 
- Data validation and constraints
- Use of modern Java features (records, stream API, Optionals, var)
- Use of Lombok, Jackson, Slf4j libraries
- TDD approach and testing with jUnit and Mockito

**Frontend (TypeScript + React 19 + next.js):**
- Functional component-based architecture
- Client-side form validation
- next.js routing
- Server-side rendering
- Responsive design with modern UI libraries (Tailwind CSS / Material UI)

**DevOps:**
- Relational PostgreSQL database 
- Docker containers working on Kubernetes cluster
- Following "12-Factor App" CI/CD approach
